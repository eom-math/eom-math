# 모바일 OMR

| 주소 | 용도 |
|---|---|
| `/omr/` | 학생: 코드 입장 → 마킹 → 임시저장 → 최종 제출 |
| `/omr/admin.html` | 선생님: 학생·코드, 시험·정답, 제출 현황, 채점·공개, 성적표 발송 |
| `/omr/report.html?t=…` | 학생·학부모: 개인 성적표 (결과 공개 후에만 열림) |

## 처음 한 번 설정
1. Firebase 콘솔 → Firestore → 규칙: `firestore.rules` 내용을 기존 규칙 블록 안에 추가하고,
   `ADMIN_EMAIL`을 관리자 로그인 이메일로 바꾼 뒤 게시.
2. `admin.html`에서 학생 등록 → 코드 발급 → '코드 안내 복사'로 학생에게 전달.

## 시험 흐름
새 시험 → 정답·배점 저장 → 응시 열기 → (학생 제출) → 마감하고 채점 → 확인 → 결과 공개 → 성적표 발송 탭

## 채점 규칙
- 한 문항에 하나만 마킹, 그 번호가 정답 목록에 있으면 정답 (복수 정답 인정)
- 미응답은 오답, '전원정답' 체크 문항은 모두 정답 → 정답 수정 후 '다시 채점'
- 석차는 동점 같은 등수, 백분위 = (아래 인원 + 동점 인원/2) ÷ 응시 인원 × 100

## 알리고 연동
알리고 API는 등록된 고정 IP 서버에서만 호출되므로 이 사이트(브라우저)에서 직접 보낼 수 없습니다.
지금은 '성적표 발송' 탭에서 CSV를 받아 알리고 대량 발송에 올리거나, 메시지를 복사해 보냅니다.
버튼 한 번 자동 발송이 필요하면 고정 IP 중계 서버를 두고 `common.js`의 `MESSAGE_TEMPLATE`을 그대로 템플릿으로 쓰면 됩니다.
