## 처음 한 번 설정
1. Firebase 콘솔 → Firestore → 규칙: `firestore.rules` 내용을 기존 규칙 블록 안에 추가, `ADMIN_EMAIL` 교체 후 게시
2. Firebase 콘솔 → Storage → 규칙: `storage.rules` 내용을 기존 규칙 블록 안에 추가, `ADMIN_EMAIL` 교체 후 게시
   (Firestore 접근 권한을 묻는 창이 뜨면 허용)

## 시험 흐름
새 시험(재시험 기준 점수 선택) → 정답·배점·단원 태그 저장 → 응시 열기 → 마감하고 채점 → 재시험 탭에서 점수 기록 → 결과 공개 → 성적표 발송

## 오답 클리닉 흐름
문항 은행에 단원별 유사 문항 등록(직접 입력·이미지·JSON) → 약점 분석 확인 → 맞춤 학습지 만들기(전체 오답자 또는 재시험 대상자만)
→ 학생 폰에서 풀이·제출 → '제출분 채점하기' → 학생 화면에 결과 표시

## 채점 규칙
- 한 문항에 하나만 마킹, 그 번호가 정답 목록에 있으면 정답 (복수 정답 인정). 미응답은 오답
- '전원정답' 문항은 모두 정답 → 정답 수정 후 '다시 채점' (재시험 기록은 유지)
- 석차는 동점 같은 등수, 백분위 = (아래 인원 + 동점 인원/2) ÷ 응시 인원 × 100
- 재시험: 기록 중 가장 높은 점수를 최종 반영, 기준 이상이면 통과

## 알리고 연동
알리고 API는 등록된 고정 IP 서버에서만 호출되므로 이 사이트에서 직접 보낼 수 없습니다.
성적표 발송·미제출 독촉 모두 CSV를 받아 알리고 대량 발송에 올리거나 메시지를 복사해 보냅니다.

## 데일리 리포트 흐름
새 수업 기록(반·날짜·회차) → 진도·다음 과제·테스트 이름·만점·보완 유형 목록 입력 → 학생별 출결·점수·과제 이행률·보완 유형·코멘트·추가학습·분석지 입력(자동 저장)
→ 리포트 발행 → 학생별 링크/메시지 복사 또는 CSV로 알리고 발송. 학생은 OMR 포털(코드 입장)에서도 최근 리포트를 볼 수 있음.
- 조교 계정: daily.html → 조교 계정 탭에서 이름·아이디·비밀번호로 생성. 조교는 아이디만 입력해 로그인(내부적으로 `아이디@ta.eom-math.app`).
- 조교는 학생 이름·반만 보고, 학부모 연락처는 볼 수 없음 (CSV의 연락처 칸은 선생님 계정에서만 채워짐).
- 발행 후 내용을 고치면 '수정 내용 다시 발행' — 같은 링크가 갱신됨.

## 운영 기능 메모
- 클리닉: 슬롯의 `count`는 예약·취소와 한 번에(batch) 바뀌고, 보안 규칙이 정원 초과를 막음. 추천 학생 = 최근 2주 ‘추가학습 필요’ + (선생님 계정) 재시험 미통과·대기.
- 영상: 유튜브 ‘일부 공개’ 영상 링크를 등록. 10초 구간 단위로 실제 본 구간만 기록하고 90% 이상이면 완강. 워터마크는 사이트 안에서만 보이며 유튜브 링크 자체의 공유는 막을 수 없음.
- 등원 알림: 알리고 서버 연동이 없어 문구 복사·CSV로 발송.

## 성적표 분석 (대치온식)
- 시험 설정의 ‘성적표 등급’: 내신 5등급(누적 10·34·66·90%, 기본) / 수능 9등급 / 표시 안 함. 석차(동점 같은 등수) ÷ 응시 인원으로 판정.
- 채점할 때 성적표에 함께 저장: 등급·표준편차·상위 %, 점수대별 인원(5구간), 등급 컷(몇 등까지), 오답률 TOP 5, 유형별 분석(내 점수·평균·상위 30%·석차), 재시험 이력, 누적 성적표(같은 반 최근 8회: 점수·등수·등급).
- 재시험 점수를 기록하면 그 학생 성적표의 재시험 이력도 바로 갱신됨. 기존에 채점한 시험은 ‘다시 채점’을 누르면 새 분석이 들어감.
- 유형 관리: 정답·배점 탭 → ⚙ 유형 관리. 대분류 › 중분류 › 유형을 직접 추가하거나 엑셀(.xlsx)·CSV·붙여넣기로 한꺼번에 등록. 문항 태그 칸에서 몇 글자로 검색.
